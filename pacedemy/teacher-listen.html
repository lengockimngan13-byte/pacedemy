Về trang học

Nhập bài nghe Part 1 đến 4

Chọn đề và Part đang soạn trước, rồi tải file lên và dán nội dung câu hỏi. Mỗi file âm thanh là một bài nghe.

Đang nhập cho

Hai ô này quyết định file tải lên nằm ở đâu trong kho và bài lưu xong thuộc đề nào. Chọn đúng từ đầu thì không bao giờ lẫn file giữa các đề.

Part

Bước 1 · Tải file âm thanh và ảnh

Chọn được nhiều file cùng lúc. File mp3 hoặc m4a cho bài nghe, file ảnh cho Part 1. File vào đúng ngăn của đề và Part đang chọn ở trên, nên hai đề đặt tên file giống nhau cũng không đè lên nhau.

Ảnh nằm trong file PDF đề — để máy tự tách ra

Thả file PDF đề vào, bấm Tự tách ảnh. Công cụ tìm các hình có sẵn trong file và cắt ra theo thứ tự — ảnh Part 1, biểu đồ Part 3 và 4. PDF bản scan thì mở từng trang rồi kéo một khung quanh hình. Ảnh tách ra cũng vào đúng ngăn của đề và Part đang chọn.

Bước 2 · Lấy câu nhắc cho Claude

Câu nhắc lấy theo Part đang chọn ở trên. Copy rồi dán vào khung chat kèm file script. Claude trả về một khối dữ liệu, bạn copy rồi dán vào ô ở bước 3.

Mỗi phần tử là một bài nghe, bên trong có danh sách câu hỏi.

Gán audio & ảnh cho từng bài

Cách này không cần đặt tên file khớp gì cả: chọn file nào là tải lên và gắn ngay vào đúng bài đó. Danh sách lấy theo đề đang chọn ở trên.
