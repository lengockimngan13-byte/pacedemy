Về trang học

Nhập bài nghe Part 1 đến 4

Tải file âm thanh lên trước, sau đó dán nội dung câu hỏi. Mỗi file âm thanh là một bài nghe.

Bước 1 · Tải file âm thanh và ảnh

Chọn được nhiều file cùng lúc. File mp3 hoặc m4a cho bài nghe, file ảnh cho Part 1. Tải xong bạn chỉ cần ghi đúng tên file vào phần dữ liệu bên dưới, hệ thống tự tìm đường dẫn.

Bước 2 · Lấy câu nhắc cho Claude

Chọn đúng Part đang soạn, copy câu nhắc của riêng Part đó, dán vào khung chat kèm file script. Claude trả về một khối dữ liệu, bạn copy rồi dán vào ô ở bước 3.

Mỗi phần tử là một bài nghe, bên trong có danh sách câu hỏi.

Gán audio & ảnh cho từng câu

Chọn Test rồi gán file cho từng bài một. Mỗi lần chọn file là tải lên và gắn ngay vào đúng bài đó, không cần đặt tên khớp gì cả.
